How the implied value is built

implied = TVL × category ratio × growth × maturity × breadth

  • Category ratio — the median market-cap-to-TVL ratio of protocols in the same category that already trade, shrunk toward the global median (prior: 5 protocols) and capped at 2.0. A category with few live tokens stays near the global ratio instead of swinging the board.
  • Growth — 1 + (7-day TVL change, clamped to −60%..+120%) × 0.5.
  • Maturity — 0.6 + (days listed, capped at 1,095) / 1,095 × 0.4. A protocol that has run longer with no token scores higher; unknown age counts as 365 days.
  • Breadth — 1 + 0.02 per extra chain, up to 4 extra chains.

No protocol name is ever special-cased: the same function scores every row. “Pre-token” means the snapshot records no token for it — never that it has none. A protocol on the list may still have a token its DefiLlama record does not carry.

Farm plans are the entry’s own suggestions, derived from each protocol’s category, chains, TVL and age. They are not investment advice, and a launch is never predicted — only priced, if it happened.
